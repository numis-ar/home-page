Esta es una nota de ejemplo. No está publicada y no tiene que publicarse: sirve para ver el formato. Copiala, cambiá el texto y borrá lo que no uses.

El primer párrafo va directo al tema. Frases cortas, una idea por oración. Le hablás a una persona, de vos.

## Un título de sección

Usá títulos de sección para ordenar notas largas. Si la nota es corta, no hacen falta. Dentro de un párrafo podés marcar algo **en negrita** y poner un [enlace a otra página](/nosotros).

### Un subtítulo

Los subtítulos van dentro de una sección. No saltes de un título de sección a nada más chico sin pasar por acá.

## Listas

Una lista sin orden, para cosas que no tienen secuencia:

- Un elemento corto.
- Otro elemento, un poco más largo, para ver cómo corta la línea cuando no entra.
- Un tercero.

Una lista numerada, para pasos que van en orden:

1. Abrí el administrador.
2. Escribí la nota.
3. Encendé "Publicado" cuando esté lista.

## Citas

> Una cita va con el filete naranja a la izquierda. Usala para palabras de otra persona, con su nombre al final.

## Código

Para nombrar un archivo o un comando dentro de un párrafo, usá código en línea: `publicado: true`.

Para un bloque de varias líneas, usá tres acentos graves antes y después:

```
fecha: 2026-09-11
publicado: false
```

Solo imágenes reales: nada de bancos de imágenes ni ilustraciones. Una imagen se escribe así:

```
![Qué muestra la imagen](/blog/nombre-del-archivo.png)
```

---

La línea punteada de arriba separa una parte de la nota de otra. Usala poco.
